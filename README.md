# UltraLauncher for iPhone

A home-screen web app companion to UltraLauncher (Android): clock styles, weather, your TV
watchlist and shortcuts, in UltraLauncher's look.

- **Install:** open the site in Safari → Share → Add to Home Screen.
- **Your data stays on your phone** (settings, wallpaper, shortcuts). The TV watchlist is shared
  through UltraLauncher's online list, read and changed only with your link code.
- Plain HTML, CSS and JavaScript; no build step. Published by GitHub Pages on every push to `main`.
